Digital Service Delivery / Salesforce / API Integration

From manual orientation scheduling to connected client experiences.

Led the design and delivery of a Salesforce-centred orientation platform that generates multiple sessions through a guided Screen Flow, provisions Zoom meetings using asynchronous Apex, and connects upcoming events to website registration.

Senior Salesforce Business AnalystIntegration Solution ArchitectTechnical LeadScreen Flows + Apex QueueableZoom REST API
01 / Executive overview

One scheduling experience, three connected platforms.

Previously, staff repeated event setup across Salesforce, Zoom and website processes. Manual meeting provisioning, copying virtual links and event administration limited the volume of orientations that could be offered.

The delivered solution centralizes scheduling in Salesforce while retaining Zoom for virtual delivery and the public website for event discovery and registration. Event creation supports date-range and selected-weekday recurrence patterns, two sessions per day in the demonstrated scenarios, and a review stage before records are created.

Delivery at a glance

Core platform: Salesforce Event/Workshop and Event Registration records

Related records: Account and Program Component

Integration: Queueable Apex with HTTP callouts to Zoom REST API

Experience: Location-filtered website journey for in-person or virtual orientations

Scope: Scheduling, meeting provisioning, registration, confirmations and reminders

02 / Business challenge

Manual handoffs became a capacity constraint.

Before transformation

Individual event creation, separate Zoom meeting setup, manual transfer of meeting details, multiple system handoffs and staff-heavy registration administration.

After transformation

Configurable session generation, pre-creation confirmation, asynchronous Zoom provisioning, stored meeting identifiers, public session discovery and associated registration records.

05 / A guided scheduling experience

Powerful batch scheduling without committing unwanted sessions.

01

Define event details

Choose in-person or virtual orientation, Event Name, Program Component, capacity, city and description.

02

Choose scheduling pattern

Date-range mode supports start/end dates, daily frequency, times and a skip-public-holidays option.

03

Schedule by weekday

Recurring mode supports selected weekdays, occurrence counts, daily frequency and session duration.

04

Review before creation

The Flow displays proposed events in a selectable table. Staff select events they do not want; those rows are removed from the collection before the remainder is created.

05

Provision and associate Zoom meetings

Asynchronous Apex provisions meetings using location-based host assignment and updates Salesforce Event/Workshop records with Zoom details.

06

Support testable integration behavior

The supplied ZoomMeetingQueueableTest class contains mocked HTTP responses covering successful responses and failure scenarios.
